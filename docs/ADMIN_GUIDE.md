# Administrator Guide

1. Create a workspace and keep its workspace slug; all users need it to sign in.
2. Open **Units** to create work units and duties.
3. Open **Requests** to invite members and review unit-switch requests.
4. Open **Schedule**, choose a date, and generate a draft.
5. Review skipped duties and fairness warnings. Reassign a draft duty if needed.
6. Publish only after review. Publishing emails assigned members; clicking publish again retries failed emails without duplicating successful sends.
7. For a published date, mark each assignment present or absent. Unmarked assignments are not counted as absences.

Admins can see all members and roster entries in their workspace but cannot access another workspace's records.
