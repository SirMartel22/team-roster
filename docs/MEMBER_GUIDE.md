# Member Guide

1. Open an invitation link or choose **Join an existing team**.
2. Create the account and select a work unit. Use the workspace slug when signing in later.
3. **My team** shows members in your current unit.
4. **Assignments** shows only your published assignment for a selected date.
5. **Requests** lets you request a move to another unit. Only one request can be pending at once.
6. **Performance** shows marked attendance. Unmarked assignments do not reduce your attendance rate.

Contact a workspace administrator if profile completion fails after account creation; the profile step can be retried without creating another account.
